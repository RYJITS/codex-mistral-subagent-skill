Classe les extraits `S1` a `S10` selon les regles `allow`, `redact`, ou `block`.

{
  "items": [
    {
      "id": "S1",
      "decision": "allow|redact|block",
      "reason_fr": "phrase courte",
      "redaction_targets": ["liste courte ou vide"],
      "normalized_excerpt_fr": "texte utile apres redaction, ou chaine vide si block"
    }
  ],
  "summary": {
    "critical_blocks": ["ids classes block"],
    "needs_redaction": ["ids classes redact"],
    "safe_to_delegate": ["ids classes allow"]
  }

Contraintes:

- Pas de Markdown.
- Garde les ids exacts.

- `normalized_excerpt_fr` doit etre vide pour `block`.
- Les raisons doivent etre courtes, concretes, et en francais.
