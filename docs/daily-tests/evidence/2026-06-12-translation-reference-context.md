# Reference cible

La reference finale doit etre en francais ASCII et expliquer un workflow de traduction FR -> EN borne pour des notes repo publiques.

Elle doit couvrir:

- quand utiliser la traduction structuree avec glossaire verrouille;
- quelles entrees minimales fournir;
- quels termes doivent rester exacts;
- quels modeles sont les plus adaptes;
- comment verifier localement la sortie avant integration.

Le texte est destine au repo public `codex-mistral-subagent-skill`.
